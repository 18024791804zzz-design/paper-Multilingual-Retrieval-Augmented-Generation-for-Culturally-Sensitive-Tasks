# 段落W与“结论反查依据”G：v3候选规范

2026-11-09。对用户“从果找因”思路的落地评估。本轮只提供规范、提示词和说明性案例，不标答案偏向性，不重标旧360条或全库，不改变原文/源码/requirements.txt。

- PROTOCOL.md：完整操作规范与NONE/G/UNK边界。
- PROMPT.txt：可直接配合一个完整原始段落使用的候选提示词。
- real_examples.json：4个项目真实单段例子，含完整原文、ID、来源与本轮G说明性判断。
- constructed_examples.json：9个构造案例，展示依据充分、仅提协议、范围扩大、引语、缺失依据、未来协商/完成、普通事件、普通地理等区别。不是语料原文。

核心是“关键结论→段内依据→支持范围”，不是要求每句事实都有原因或协议。来源归属、证据支持和事件因果分开判断；没有依据不自动证明偏见；有协议名称不自动证明支持充分；段内自洽不等于世界事实真实。

全部示例仅使用当前完整段落；不包含相邻段落。W保留前版五类，但以完整语义而非词语命中判断。G不再强制按旧G1-G5查找；错误机制可写入简短理由。

所有标签为当前助手的协议示范，不是独立验证集，没有测量F1或RAG影响。未调用额外收费模型API。本包不设置强制独立人工审核环节。

真实原文来自已发布三组试标包v1.1；保留页面入口、原始文件/字段以供追溯。适用维基百科页面的许可及署名要求，不能把原文当作代码MIT许可。当前网页可能变化，示例应使用冻结原文。
