# W与来源归属G：v4候选规范

此版采用用户指定的边界：G检查信息来源/观点主体是否明确归属，不校验来源内容是否足以支持结论。本轮不处理答案偏向性。

## 1. 范围与定义

只读项目原有的完整目标段落，不读相邻段、全文、其他检索结果或旧标签。不联网查每份协议，不凭标题/模型记忆推测条款，不验证来源是否真实存在、是否生效或法律解释是否正确。

G：在当前段落可辨认的归因缺失、来源主体错置或归属混淆。G不是所有事实错误、逻辑矛盾或依据范围扩大的总标签。

NONE（G维度）：当前没有发现来源归属问题，不等于事实、推理、法律解释或整个段落已经通过质量验证。W仍独立评估；G为NONE不自动意味着最终bias_label为NONE。

## 2. 按来源归属检查，而非按依据充分性检查

1. 找出需要检查的主张或判断，保留其原文表达及限定。
2. 判断段落将该说法归给谁/什么资料：例如具名协议、可识别的报告或裁判、政府声明、当事方意见。
3. 检查该来源是否明确与该项判断相联系，而非仅在同段出现一个无关名字。不要求完整书目信息、联网可访问链接或逐字条款。
4. 来源与说法的归属清楚时，不因没有给出条款、没有外部核验或依据看起来不充分而判G/UNK。
5. 只在段内能定位归因错置/混淆等问题时确认G。对于确实需要归因但无法识别主体的疑难情况保留UNK。普通事实简述不因没出处就自动判G或UNK。

“根据《X协议》，……”是已表达的来源归属。本轮不接着要求证明X协议是否真的写了这件事。反之，某段提到《X协议》不表示该段其他所有主张都自动获得归因；必须按每个主张与来源的联系阅读。

## 3. 本版不纳入G的内容

- 协议原文是否真的包含转让条款。
- 作者对条款的理解、推论或法律解释是否成立。
- 部分推至全部、临时推至永久、协商推至完成等内容扩大——若来源归属仍清楚，不单因这种内容问题判G。
- 有明确来源的结论与同段其他内容是否逻辑一致。

这些问题可能影响文本质量，但本版不以G计分，也不为它们强制新增标签。不能为了保留旧G判断而机械改判W。

需要特别说明：S03的“不涉及领土权属”来自正文，不是从“通航协议”名称猜出来的；原文确有明示的内容冲突。v4将它判为NONE(G)，是因为本版只测来源归属，不是因为冲突不存在。

## 4. 示例修订

| 例子 | v3 | v4的G维度 | 理由 |
|---|---|---|---|
| S02：有具名边界协议，未列条款 | UNK | NONE | 来源归属明确，不要求核验内容 |
| S03：通航与主权结论冲突，但明确引用该协议 | G | NONE | 来源归属明确；内容冲突不计入本轮G |
| S06：未来协商被推为已完成 | G | NONE | 同样不把事件状态推论问题计入来源归属G |
| S09：部分/临时被推为整体/永久 | G | NONE | 同样不把条款范围解释计入来源归属G |
| S05：仅一句重大同意/让渡断言，没有出处 | UNK | UNK | 是否属于需归因的争议判断仍不清楚；不是缺少联网验证 |
| S10：把同一份A国声明M1的来源改成法院判决M1 | 新增 | G | 段内可定位的来源身份错置 |

原9个示例的段落文字完全保留，仅修改标签、理由和审计字段。S10是新增构造示例，不是语料原文。

## 5. W与输出

W保留W1贬损、W2褒扬、W3确定性、W4情绪隐喻、W5言说可信度倾斜。完整阅读段落，处理主体、引语、否定、语气与事实行为；不以词语命中判定。G维度NONE时，也不能预设W必须成立或必须不成立。

核心输出bias_label仍为NONE、UNK、W1-W5、G及已确认组合。只对风险/疑难项保存claim_quote、attribution_quote（未显示可为null）、reason。NONE无需长解释。

若G已明确无风险而W未测，应写G_demo_verdict=NONE、W_assessed=false，不把它当作整段最终NONE。

## 6. 状态

本版是操作规范和10个构造示例，没有覆盖v3，没有重标旧360段或全库，也没有测模型准确率/F1。源码、requirements.txt和原始语料不变。不调用额外收费模型API。
