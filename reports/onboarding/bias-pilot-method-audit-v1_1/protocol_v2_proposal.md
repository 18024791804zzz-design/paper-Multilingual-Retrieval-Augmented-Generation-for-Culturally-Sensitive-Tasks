# 标注协议 v2 提案：先分清文本风险与RAG效应

这是方法修订提案，本轮没有按此重标全部120条或扩标240条。

1. 主标注输入恢复为实际query_id、query_text、query_lang与目标doc_text。W/G的文本特征可缓存，但任务相关性、主张方向、信息呈现不能未经验证跨语言查询复用。
2. 逐段主标签保留W（有证据的不当措辞/预设）、G（可确认的争议主张归因问题）、NONE和UNK。带负面词、形容词、强迫动词或缺少脚注都不是充分条件。程序抽取时已经删除ref，不能把抽取无引证当原文无依据。
3. 不再强制给每段判I。篇章中的信息选择可以在有充分对照材料时判断；RAG主实验中I的重点改为query+实际top-k证据集合的选择/覆盖审计。只描述单方曝光及关键事实覆盖，不把不对称自动称为偏见。
4. 区分原文上下文与模型可见上下文。原文章相邻段用于理解代词和核查发言主体；若它们未送给RAG，不能据此直接消除RAG输入中的断章取义风险。
5. 保留原始relevance和viewpoint作为带来源的参考。对归属有直接信息的证据与背景/无关负例分层统计，不将NONE一概当高质量中立证据。原观点噪声较大，不作偏见真值。
6. 所有W/G先视为模型识别的文本风险；其是否改变生成选择，需另做内容、事实、国家、强制成分和文档顺序尽量相同的措辞干预。FlipRate及候选分数差只衡量敏感性，改变不等于改善。
7. 先对原120条按修订标准复标做可比性检查。若再抽两组各120，应固定候选范围，按领土划分互不重合组，再按语言、检索器及rank1-10/11-50分层。报告跨组重复文章/段落，不宣称三组完全独立。
8. 不强制增加人工审批步骤；结果仍称自动弱监督，重复一致/不同模型一致不能替代独立准确率。
