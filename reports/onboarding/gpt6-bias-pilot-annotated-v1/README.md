## 标签解释与边界

W=不当措辞/预设；I=有上下文证据的信息呈现偏向；G=争议主张/法律解释的归因问题。NONE只表示给定范围内未发现，不能证明客观中立。UNK不作为0或NONE处理。

方向固定为**明确的主权/领土归属主张方向**：行政管理、军港或人口资料不自动表示合法主权。NEUTRAL=目标段没有支持单一方的主权论证；MIXED=多方主张实质并列；UNKNOWN=方向无法判断。仅说“存在争议”一般NEUTRAL。

类型与方向是两个独立判断；`W::Israel`不等于“亲以偏见”：该例的W来自针对以军无敌神话的评价，而方向来自同段记录以方东耶路撒冷主张。用单一字段不能进一步统计偏见褒贬对象。`W::Italy`所指可为意方共享峰顶主张，不表示意大利独占。

有归因引语中的“非法占领”不自动算百科作者偏见。对政策、战争、矿业等负面事实，不因其负面就判W/I。国家背景无关不等于I；全文或top-10的选择失衡不能回填成每段偏见。法理、时间和地理范围无法确认者保留UNK。

当前助手此前已在本会话见过部分实例；本次不是独立盲标，也不是另外运行GPT-6高推理API后的结果。判断只使用冻结原文和所给上下文，没有外部法律事实核查或独立人工审核环节。
