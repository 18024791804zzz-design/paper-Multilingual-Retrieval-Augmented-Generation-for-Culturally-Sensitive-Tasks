360个“领土—段落”对象，30个不同领土；第一组为修订后的120段，新增随机两组各120段。当前助手直接完成新增标注，没有额外收费API调用。原文未改写，源码和requirements.txt未修改。

## 先看哪里

解压后直接打开 **index.html**，可按组、领土、风险/未知筛选；每条都有完整原文、标签、中文理由、证据高亮、源文件位置和上下文。无需安装环境或启动服务器。

- annotations.csv：Excel可直接打开的完整360行表（UTF-8 BOM）。
- groups/：三组各自的CSV和JSON，便于分别查看。
- flagged_cases.csv / uncertain_cases.csv：明确标记风险与不确定项。
- labels.json：最简ID→bias_label；annotations.jsonl保留完整元数据。
- audit/：随机种子、抽样框、所有检索来源/模式/排名/分数、原查询和原文哈希、上下文、第一组修订依据及新增疑难复判记录。

## 抽样保持了什么

第一组沿用修订版v1.1：B10-D05从W::NEUTRAL撤回为UNK::NEUTRAL，另119条保持不变。第一组原来是目的性试标，不改称随机组。

新增两组从原121个合格领土中排除第一组10个，剩余111个按名称排序，用`random.Random(20261105).sample(frame,20)`抽取；前10个为G2，后10个G3。组间无重复领土，不因偏见强弱重抽。原资格规则：两声索方、指定语言不同、双方查询可用，排除声索方含PRC/ROC。国家背景中提到中国不因此删段。

每领土12段：双方各自OpenAI qlang top-3，共6段；再按双方各取M3独有候选、具有11–25排名的候选、具有26–50排名的候选，共6段。候选来自两检索器×qlang/rel_langs的预计算top-50并集。新增240段无需备用抽样。文档随机种子为20261105+批号；完整来源保存在audit中。分层可含交叉属性，stratum只记录选入理由，不意味着该段只出现在对应模式。

这是360个不同的(territory,doc_lang,doc_id)标注对象，涉及352个不同(doc_lang,doc_id)，352个不同原文哈希、27个文档语言代码。不同领土可能共享同一段；千岛/南千岛、河流/相邻争议区等对象还存在主题相关性，不能把360项当作独立抽样估计总体偏见比例。原样本含地理背景、目录或与具体归属关系很弱的段落，NONE也包含这些材料，不等于“相关且高质量”。

## 标签怎样解读

沿用annotation_instructions.txt的W/I/G。W要求可辨识的不当评价/预设，强迫、占领等字词不是自动触发器；I要求给定上下文能支持信息呈现问题，不以单段只讲一方为依据；G用于应归因的争议观点/法律解释被直接当叙述者事实。NONE仅是当前范围未发现明确问题；UNK保留判断不足，不当作NONE。

`类型::方向`的两部分独立。方向是段落明确呈现的主权/领土归属主张，国家使用规范声索方名称；NEUTRAL=目标未明确支持某一主权论证，MIXED=多方主张实质呈现，UNKNOWN=不能判明。单纯实际管理、行政区划、国家关键词、历史控制、对某国的负面评价不自动确定方向；历史权源若作为当前诉讼论据明确提出，可记录其声索方向。比如NONE::Singapore可表示有归因的法院裁决，不能读成“亲新加坡偏见”。G::NEUTRAL可表示文化起源观点丢失归因，但不能据此推断现代主权方向。

标注单位仍是**territory_doc**：围绕同一领土的规范问题判断段落，不是把每个原语查询都独立重判。manifest保留对应原query_id/query_text及检索记录，关联回查询时应保留这一范围。合并候选用于去重标注，不改变原始排名，也没有实际重排或RAG生成。

## 可信范围

这是当前助手的自动/弱监督标注，没有独立准确率或人工金标准，也不是另外调用固定版本GPT-6高推理API得到的实验。未要求独立审核流程；你可以直接使用或自行复核。目标原文逐字保留，不做自动修订。对source context的判断不能直接证明RAG实际能看到这些上下文，也不能证明所标措辞导致模型输出变化。

首轮使用相邻±1段、每上下文最多1200字符；新增13条UNK均补读相邻±3段、每段最多4000字符，仍未解决，保留UNK。完整目标不截断；上下文截断有标记。维基百科抽取可能移除ref，缺少可见引用并不自动判G。本轮无外部法律裁决或史实核查。
