# 段落W/G新标准评估与全库表达线索统计

2026-11-05。本包回答原论文F1的含义、新规则如何限定段落、W/G如何细分以及多语言表达在全库出现多少。**频率是词表候选命中，不是偏见检出率；没有全量语义重标，没有改动旧360条、原文、源码或requirements.txt。**

## 阅读顺序

1. paper_F1_and_main_results.md：F1计算和它对主实验/机制解释的影响。
2. WG_rubric_v2.md：10个候选子类，每类含成立条件、反例与数个词语。
3. answer_support_methods.md：观点分类困难、前人方法与下一步候选方案。
4. index.html：离线浏览286个完整单段例子，可按类别和语言筛选；这些没有被判为偏见。
5. scan/term_frequencies.csv：1663个词条的出现次数与包含段落数，分别统计raw/indexed。
6. scan/category_language_frequencies.csv及language_coverage.csv：每语言分母、词表覆盖和匹配规则。

## 全量范围

945篇有效原始文章，51个语言代码，62359个原始段落，其中62349个非空；52个metadata JSON没有当作正文。实际检索索引为25311段、50个非空语言代码；另有control空键。原论文查询语言为49，不应把这些数字混为一谈。未排除中国相关材料，未筛去标题/目录/无关国家背景。

词表含51语言代码的1663个词条；**为助手提出的未独立验证种子表**，翻译、同义词和词形覆盖不均。扫描覆盖全部段落，不代表词表穷尽全部偏见表达。英语等按Unicode词边界匹配；中日泰等使用字面子串；无词形还原、未统一分词，也没有跨语言校准。0命中不表示不存在相关表达或偏见。

初始词表中pacífico/pacifique可能误碰太平洋，已替换为更明确短语；波斯语مسلم的歧义词已移除；阿/波斯/希伯来/乌尔都改用词边界以减少非目标子串。相关前后变化是词表修订，不是模型偏见性能改进。

同段可命中多个组，不能相加成偏见总数；词条之间也可能重叠。G1中sovereignty等词本来就可能是必要事实，G2中occupation也可指职业；G3中目的状语不必涉及政治动机。ATTR是归因标记对照，不是G5。

G5需要段内语义分析，本轮不提供G5偏见频率。任何W/G类别的真实频率，都需要执行该类别的段落语义判定才能得到；本包没有用规则命中代替这些判断。

## 复跑

```shell
python scan_corpus.py --archive /path/bordirlines.zip --corpus /path/data/raw/wikipedia --out /path/new-scan
```

只需Python标准库。原文不改写，相邻段落不拼接。candidate_occurrences.csv保留每次命中的来源和Unicode codepoint起止位置；representative_examples.jsonl为各非空语言/类别格随机选一个完整段落（seed20261105），不是按偏见强弱选择。

完整性检查与语义准确率不同：verify.py校验频次汇总、哈希和引用；它不验证词表翻译或偏见真值。来源与许可见SOURCES.md。
