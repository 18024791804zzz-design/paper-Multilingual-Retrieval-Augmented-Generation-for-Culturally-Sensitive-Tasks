# WJ corpus audit download

[Download the full audit archive](wj-corpus-audit-results.zip). On the GitHub file page, use Download raw.

The archive covers structural indexing of 945 article JSON files / 62,359 article-array entries and evidence-backed lead/keyword-excerpt screening of multilingual topic groups. It contains the field mapping, article/entity tables, original paragraph index and text, per-topic findings, source quotations, quality warnings, and a searchable offline HTML viewer. It is not an exhaustive multilingual expert determination of political bias. Provisional entity alignment, empty articles, same-origin Chinese variants and temporal/scope differences are explicitly retained.
